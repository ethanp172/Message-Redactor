# Message-Redactor
This program will randomly redact messages based off a given percentage. It reads from 1 .TXT file and returns the redaction into another .TXT file.

`REDACT` = the character for redaction

`PERCENT` = % of words that will be redacted

`open_path` = path for text to be redacted

`return_path` = path for the output
