# Message-Redactor
This program will randomly redact messages based off a given percentage. It reads from 1 .TXT file and returns the redaction into another .TXT file.

`REDACT` = the character for redaction \n
`PERCENT` = % of words that will be redacted \n
`open_path` = path for text to be redacted \n
`return_path` = path for the output \n
